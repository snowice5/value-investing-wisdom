# Value Investing Wisdom

A warm, Buffett-inspired value investing quote page built as a simple static website.

Open `index.html` locally for the English version, or `zh.html` for the Traditional Chinese version.
You can also publish this folder with GitHub Pages.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository.
3. Go to the repository's Settings > Pages.
4. Set the source to the `main` branch and `/root`.
5. Share the published GitHub Pages URL.

After publishing:

- English: `https://YOUR-USERNAME.github.io/YOUR-REPO/`
- Traditional Chinese: `https://YOUR-USERNAME.github.io/YOUR-REPO/zh.html`
